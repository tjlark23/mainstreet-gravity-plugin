# mainstreet gravity for Claude

mainstreet gravity is the system local media companies use to run their newsletter, website and local directory in one place. This plugin connects Claude to your mainstreet gravity workspace so you can ask for what you need in plain words.

## What you can do

- Ask what is happening in your town: events this weekend, new businesses, open jobs and recent stories.
- Start next week's newsletter, fill a section with real local items, write the intro and pick a subject line.
- Turn notes, a link or a press release into an article and file it as a draft for review.

A person approves everything that goes out. No tool sends or schedules a newsletter, and publishing is off unless an Owner or Admin turns it on.

## Setup

1. Install the plugin in Claude. In Claude Code, run:

   ```
   /plugin install mainstreet-gravity --marketplace tjlark23/mainstreet-gravity-plugin
   ```

2. When Claude asks you to connect mainstreet gravity, sign in with your mainstreet gravity login.
3. Pick the brand, tick what Claude may do and press Allow.

You can review or revoke the connection any time in mainstreet gravity under Settings, API keys.

## What's inside

- The mainstreet gravity connector at `https://app.mainstreetgravity.com/api/mcp`.
- Three skills: `local-roundup`, `newsletter-draft` and `article-draft`.
